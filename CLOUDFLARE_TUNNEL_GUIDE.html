🌐 Cloudflare Zero Trust Tutorial (ระดับง่ายสุด)

คู่มือการเชื่อมต่อ Cloudflare Tunnel เข้ากับโดเมน udvec.go.th

ต่อท่อจากเครื่องคอมพิวเตอร์/เซิร์ฟเวอร์โรงเรียน ออกสู่อินเทอร์เน็ต • ไม่ต้องฟอร์เวิร์ดพอร์ต • ไม่ต้องมี Public IP • ได้ HTTPS ฟรีตลอดชีพ

💡 เข้าใจง่ายๆ: Cloudflare Tunnel ทำงานอย่างไร?

ปกติถ้าจะเปิดเว็บจากในโรงเรียน เราต้องขอ Fixed Public IP และต้องไปขอให้ฝ่ายเครือข่ายตั้งค่า Forward Port (พอร์ต 80, 443) ในเราเตอร์ ซึ่งมักจะติดปัญหาไฟร์วอลล์ของกระทรวงฯ หรือ สอศ.

✨ พระเอกคือ Cloudflare Tunnel:

มันจะ "เจาะท่อจากข้างในเครื่องเราวิ่งออกไปหา Cloudflare เอง" (เหมือนการเปิดดู YouTube ที่ไม่ต้องเปิดพอร์ตเราเตอร์) แล้ว Cloudflare จะทำหน้าที่ดึงคนทั้งโลกที่พิมพ์ https://udvec.go.th มุดท่อนี้เข้ามาเปิดดูหน้าเว็บในเครื่องเราได้ทันที ปลอดภัย 100%!

ขั้นตอนการปฏิบัติงาน

6 ขั้นตอนง่ายๆ ขอแค่ใช้คอมเป็นก็ทำตามได้ทันที

1

การผูกโดเมน udvec.go.th เข้ากับ Cloudflare (ทำครั้งเดียว)

💡 ไม่ต้องโทรหาบริษัทที่ขายโดเมนครับ! แค่ล็อกอินเข้าหน้าเว็บที่คุณซื้อโดเมนมา (เช่น เว็บ THNIC) แล้วเข้าไปที่เมนูจัดการโดเมน

1.1 เข้าเว็บ dash.cloudflare.com สมัครสมาชิกฟรี ➔ กดปุ่ม "Add a domain"

1.2 พิมพ์ชื่อโดเมน `udvec.go.th` ➔ เลือกแพ็กเกจ Free ($0)

1.3 Cloudflare จะโชว์ชื่อ Nameserver 2 ค่า (เช่น ns1.cloudflare.com, ns2.cloudflare.com)

1.4 นำ 2 ค่านี้ไปแปะในหน้าเว็บจัดการโดเมนที่คุณซื้อมา (หรือส่ง 2 ค่านั้นให้แอดมินไอทีช่วยเปลี่ยนให้ได้เลยครับ ใช้เวลาแค่ 1 นาที!)

2

เข้าไปที่หน้าเมนู Zero Trust

2.1 มองที่แถบเมนูด้านซ้ายสุดของหน้าจอ คลิกที่คำว่า "Zero Trust"

2.2 (เฉพาะคนเข้าครั้งแรก) ระบบอาจจะให้ตั้งชื่อทีม (Team name) ให้พิมพ์ชื่ออะไรก็ได้ เช่น udvec-team แล้วเลือกแพ็กเกจ Free Plan

3

สร้างท่อใหม่ (Create Tunnel)

3.1 ในหน้าต่าง Zero Trust ให้มองเมนูซ้ายมือ เลือก: Networks ➔ Tunnels

3.2 กดปุ่มสีฟ้า "Add a tunnel"

3.3 เลือกประเภทเป็น Cloudflared ➔ กด Next

3.4 Name your tunnel: ตั้งชื่อท่อ เช่น udvec-tunnel แล้วกด Save tunnel

4

ก๊อปปี้คำสั่ง 1 บรรทัดส่งให้แอดมิน (ไม่ต้องแตะไฟล์ .env เลย!)

ในหน้านี้ ให้กดเลือกแท็บ Docker

🎯 วิธีที่ง่ายที่สุดในโลก (แอดมินชอบมาก):

Cloudflare จะมีกล่องคำสั่งสีดำยาวๆ ให้กดปุ่ม "Copy" ได้เลย หน้าตาคำสั่งจะคล้ายแบบนี้:

docker run -d --name cloudflared --restart always cloudflare/cloudflared:latest tunnel --no-autoupdate run --token eyJh...

👉 หน้าที่ของคุณ: แค่ก๊อปปี้คำสั่งนี้ ส่ง LINE ให้แอดมินไอที แล้วบอกว่า: "พี่แอดมินครับ ช่วยเอาคำสั่งนี้ไปแปะรันในเซิร์ฟเวอร์ทีเดียวจบเลยครับ" (ไม่ต้องไปเปิดไฟล์ .env หรือแก้โค้ดอะไรทั้งนั้น!)

เมื่อแอดมินกดรันในเซิร์ฟเวอร์เสร็จ หน้าจอ Cloudflare ของคุณจะขึ้นจุดสีเขียวว่า ● Connected แปลว่าท่อทะลุหากันแล้ว ให้กดปุ่ม Next

5

ตั้งค่าชื่อโดเมนที่จะให้คนเข้า (Public Hostname)

หน้านี้คือหัวใจสำคัญ! จะเป็นการบอกว่า คนพิมพ์โดเมนนี้ ให้วิ่งมุดท่อไปเปิดหน้าเว็บที่พอร์ตไหน:

Subdomain: เว้นว่างไว้ (หากอยากให้เข้าตรงๆ udvec.go.th) หรือพิมพ์ vecsmart (ถ้าอยากให้เป็น vecsmart.udvec.go.th)
Domain: เลือก udvec.go.th
Path: เว้นว่างไว้
Type: เลือก HTTP
URL: พิมพ์ localhost:80 (หรือ frontend:80 ถ้าใช้ใน docker network)

กดปุ่ม "Save tunnel" ด้านล่างขวา เป็นอันเสร็จสิ้นกระบวนการทั้งหมด!

6

ทดสอบเปิดใช้งานจริงจากมือถือ หรือเน็ตข้างนอก!

6.1 หยิบโทรศัพท์มือถือของคุณขึ้นมา (ปิด Wi-Fi แล้วใช้ 4G/5G เพื่อจำลองว่าเป็นคนจากข้างนอก)

6.2 พิมพ์ชื่อโดเมนของคุณ: https://udvec.go.th

🎉 หน้าเว็บ UDPVECSmart จะเปิดขึ้นมาทันที พร้อมกุญแจเขียวปลอดภัย (HTTPS) เรียบร้อยแล้วครับ!

🛠️ เกร็ดน่ารู้ & แก้ปัญหา (Troubleshooting)

  • ถ้าเปิดเว็บแล้วขึ้น Error 502 Bad Gateway: แสดงว่าเครื่องเซิร์ฟเวอร์ยังไม่ได้กดเปิดระบบเว็บ (พอร์ต 80 ยังไม่รัน) ให้แอดมินรัน Docker ให้เรียบร้อยก่อน
  • สลับโหมดง่ายมาก: ในอนาคตถ้าอยากย้ายเซิร์ฟเวอร์ไปเครื่องอื่น ก็แค่เอา Token นี้ไปรันที่เครื่องใหม่ ไม่ต้องแก้ DNS โดเมนเลยแม้แต่ตัวเดียวครับ
