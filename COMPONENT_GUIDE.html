🧩 React Component & Code Architecture Guide

แผนที่โค้ด & คู่มือชี้เป้าการแก้ไขส่วนต่างๆ ของเว็บ

เจาะลึกโครงสร้าง React Component • อยากแก้ตรงไหน ไปที่ไฟล์ไหน • ข้อมูลในระบบจะหายไหมเวลาอัปเดตโค้ด?

🛡️ คำถามสำคัญ: "ถ้า ผอ. สั่งเปลี่ยนสีกราฟ แล้วเราอัปโค้ดใหม่ ข้อมูล/รหัสผ่านในระบบจะหายไหม?"

👉 คำตอบคือ: "ไม่หายเด็ดขาด 100% ครับ!"

ทำไมถึงไม่หาย?

เพราะระบบของเราใช้เทคโนโลยี Docker Volume (pgdata) ซึ่งทำงานเหมือน "ตู้เซฟฝังดิน" แยกออกจากตัวโค้ด:

  • โค้ดเว็บ (Frontend/Backend): เหมือน "สีทาบ้าน หรือ ป้ายร้าน" เราสามารถเปลี่ยนสี รื้อโค้ด เขียนใหม่กี่รอบก็ได้
  • ข้อมูลจริง (Database Data): รหัสผ่าน, ข้อมูลนักเรียน, รายชื่อโรงเรียน ถูกเก็บถาวรอยู่ในตู้เซฟ

✨ เมื่อแอดมินสั่งคำสั่ง git pull แล้ว docker compose up -d --build หน้าเว็บจะเปลี่ยนสีกราฟทันที แต่ข้อมูลและรหัสผ่านของผู้ใช้ทุกคนจะยังอยู่ครบถ้วนสมบูรณ์ 100% ครับ!

2 อยากแก้ข้อมูลใน "แท็บระบบทวิภาคี & ห้องเรียนอาชีพ"

📍 ไฟล์หลัก: frontend/src/components/dashboard/DveCareerSection.tsx

  • ค้นหาคำว่า: "ตารางแสดงจำนวนนักเรียนระบบทวิภาคี" หรือ "โครงการห้องเรียนอาชีพ"
  • ไฟล์นี้จะคุมทั้งการแสดงกราฟสัดส่วนแผนกวิชา, รายชื่อโรงเรียนมัธยมเครือข่าย, และตารางเจาะลึก
3 อยากแก้คำ หรือเปลี่ยนข้อความบนหน้าเว็บ แต่ไม่รู้ว่าอยู่ไฟล์ไหน?

💡 เคล็ดลับลับของโปรแกรมเมอร์ (Global Search ใน VS Code):

1. กดปุ่มลัด `Ctrl + Shift + F` ในโปรแกรม VS Code

2. พิมพ์ข้อความภาษาไทยที่คุณเห็นบนหน้าเว็บ (เช่น คำว่า "สำนักงานอาชีวศึกษาจังหวัดอุดรธานี")

3. VS Code จะกวาดหาไฟล์ที่มีคำนี้ทั้งหมดขึ้นมาให้คุณคลิกเข้าไปแก้ได้ทันที!
